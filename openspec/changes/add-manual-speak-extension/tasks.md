# Tasks

Owner mapping (initial recommendation): the user permits only the `oracle` subagent, so every implementation task is owned by the Orchestrator (main agent). `scout`, `researcher`, `worker`, `fixer1`, and `delegate` are not used. Specs, ADRs, and this file are Orchestrator-owned. Each numbered wave ends with exactly one `oracle` review gate; do not add per-task or per-slice Oracle reviews.

Review fallback: if the `oracle` subagent is unavailable in the host, the user has authorized the caller to perform the wave review itself. Such a review follows the same `review-convergence` rules, is recorded in the review log as a caller self-review, and is never described as an Oracle review.

Scope reminder: v1 omits the features in `design.md` under "Deferred Capabilities". Do not implement `/speak summary`, confirmation tiers, secret-pattern blocking, `/speak cache-clear`, or usage accounting; `summary` and `cache-clear` only report "not available in this version".
